Staff guide

How to run a season. Staff-only buttons are hidden from tippers.

New season · Load races · Start list · Race day · Edit a race · Tipp for someone · Tippers · Point adjustments · Rescore · FIS limits

Start a new season

  1. Go to Season → New.
  2. Enter the name (e.g. 2026/2027) and start and end dates.
  3. For FIS calendar, use the men's World Cup calendar for the season, e.g. https://www.fis-ski.com/DB/alpine-skiing/calendar-results.html?sectorcode=AL&seasoncode=2027&categorycode=WC&gendercode=M. FIS numbers seasons by their end year.
  4. Tick Current.
  5. Tippers are copied from the last season. Remove anyone who isn't playing (see Tippers).
  6. Click Create Season.
  7. Open last season from the season menu, go to Season → Edit and untick Current. Only one season should be current.
  8. Load the races and update the start list.

Load races from the FIS calendar

  1. Go to Season → Edit. The FIS calendar loads on the right, which takes a few seconds.
  2. Tick the races to add, or use Select all. Races already added are ticked and greyed out.
  3. Click Load races.

Only men's races are listed. If you load a whole season at once, FIS may stop answering partway through (FIS limits). Wait a minute, reload the page, click Select all again and load the rest.

FIS adds start times later in the season. Until then a race shows midnight on race day, which closes tipping early. Use Update details from FIS on the race to pick up the real time.

Update the start list

User menu → Update Start Lists. This loads the current World Cup start list from FIS and sets which racers tippers can choose. Run it at the start of the season and whenever new racers appear in races.

Race day

  1. Tipps saved after the race start time don't count.
  2. Publish tipps on the race page closes tipping and makes everyone's tipps visible. Any logged-in user can do this once the race has started.
  3. When FIS has the results, click Score Race. This fetches the results and scores every tipp. If FIS changes the results later (e.g. a disqualification), click it again.

Edit a race

On the race page click Edit. You can change:

  • Location and Short name (max 10 characters, used on the leaderboard).
  • Race date. Update details from FIS overwrites it until the race is scored.
  • Points multiplier, e.g. 2 for a double-points race.
  • Is classic: the single best tipper gets +2 instead of +1.
  • Cancelled: marks the race cancelled and stops tipping.

Changes to the multiplier or classic only count after you click Score Race again.

To delete a race, use the delete link on the edit page. This also deletes its tipps.

Enter or correct a tipp for someone

There is no button for this. Open this address, replacing the race ID and username:

{{ request.scheme }}://{{ request.get_host }}/app/season/{{ selected_season.pk }}/race/<race FIS ID>/manual_tipp/<username>

The race FIS ID is shown on the race page. A tipp entered here counts even after the race has started. Then click Score Race if the race is already scored.

Tippers

New tipper

  1. They sign up on the login page.
  2. Members of the Season Admin group get an email with an activation link. Click it, and the tipper is emailed that their account is active. You can also activate them in Admin → Users by ticking Active.
  3. Add them to the season: Season → Edit, select them in Tippers, Save Changes.

Remove a tipper

Season → Edit, deselect them in Tippers, Save Changes. Their past tipps are kept. Hold Ctrl (Cmd on Mac) when clicking, or the list selects only that one person.

To stop someone logging in at all, untick Active in Admin → Users.

SMS reminders go to the mobile number on the user's page in Admin → Users.

Point adjustments

Use Points to add or remove points for a tipper, with a reason. Preseason marks points carried in before the first race. Applicable to sets whether they count on the overall leaderboard, the discipline leaderboards or both. Delete an adjustment with the x next to it.

Rescore the season

Open the Overall leaderboard and click Rescore all Races (current season only). This refetches results for every scored race and recalculates all points. Use it after changing scoring rules or fixing several races. For one race, use Score Race on that race instead.

If FIS stops answering partway through, the remaining races are scored from the results already saved, and a warning says from which race.

FIS limits

FIS stops answering after about 40 requests in a short time. You'll see a yellow warning saying so. Nothing is lost: wait a minute and repeat the action. Loading the calendar uses about 20 requests, and each race loaded or scored uses one.

If something fails without that warning, FIS has probably changed its page layout, and the scraper needs fixing.
